ORIGINAL MODEL / NEW ANALYSIS WORKSPACE

Apple product review sentiment

This project classifies customer reviews using the original saved TensorFlow/Keras model, tokenizer, and label encoder.

Preprocessing
Saved tokenizer; post-padding and post-truncation at 350 tokens.
Review flags
Top score below 70%, vocabulary coverage below 50%, or input truncation. These are review heuristics, not validated business rules.
Evaluation
No held-out evaluation results are included in the repository. No accuracy, lift, or ROI claim is made.
Domain limits
Trained for Apple product feedback, not collections, credit risk, or call transcripts. A new domain needs labeled evaluation data before operational use.
Privacy
Inference runs on the application server. Review history lives only in this browser tab and clears when the page reloads.

Model version is available after the first analysis.
